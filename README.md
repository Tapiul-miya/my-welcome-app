# my-welcome-app

Simple Kivy-based welcome app for Python.

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Build for Android

Install Buildozer and run:

```bash
buildozer init
buildozer android debug
```

If you want, I can also help you create a more polished UI or prepare the project for a full Android APK build.
